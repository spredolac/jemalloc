jemalloc / shared16_64 / architecture

Reuse medium allocations
before the page allocator.

A bounded shared cache retains complete large allocations with usable sizes greater than 16 KiB and up to 64 KiB. Ordinary tcache stays in place. Threads using the same arena group can reuse each other’s freed objects.

Opt in · off by defaultPAC or HPA backingNo size routing requiredNo per-CPU cache or rseq

Shown with tcache_max:32768. On a 4 KiB page build, slab classes end at 14 KiB; the exact 16 KiB class is large and follows the existing tcache → arena path. The new cache excludes exactly 16 KiB.

Background threads trim each class’s cold tail using its low-water mark. Without them, capacity bounds still apply. Explicit experimental.shared_cache.flush releases cached inventory; concurrent producers can refill it.

Sharing follows arenas, not CPU IDs.

The default is one cache per automatic arena. Increasing the arena-group size lets fewer caches serve more arenas. A returned object keeps its original arena and HPA/PAC ownership even when another arena in the group reuses it.

1

This example has eight automatic arenas. Group = floor(arena index / arenas per group). Each group’s 1.5 MiB budget is split across usable large size classes and rounded down to whole backing extents. The budget is independent of how many arenas share the group.

Budget includes padding

A 64 KiB usable object may occupy a 68 KiB extent on a 4 KiB cache-oblivious build. Shared-cache accounting charges all backing bytes. HPA and SEC admission also use backing extent size.

HPA is a separate choice

This option works with PAC too. If testing HPA for the full range, ensure its slab allocation limit admits the padded backing extent; setting the shared-cache option alone does not change that limit.

Reuse before page reuse

A hit avoids a page allocator operation. Trimming returns cold objects so HPA/PAC can reuse their pages. Metadata is additional; cached bytes remain allocated in ordinary arena statistics.

The calling thread’s automatic tcache must be enabled. Sampled, guarded, manually created arena and explicit tcache paths bypass the cache. Larger-than-64 KiB objects follow existing paths.
